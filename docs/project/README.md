# Estado del proyecto

Documentos de trabajo, no referencia del código: pueden quedar desfasados entre merges. `STATUS.md`
tiene el estado verificado y los pendientes; `ROADMAP.md`, el orden para terminar la app;
`HANDOFF.md`, el resumen corto para retomar; y `REPO-AUDIT.md`, la auditoría con el plan P0/P1/P2.
